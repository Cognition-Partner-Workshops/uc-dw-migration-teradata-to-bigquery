### `properties_v`

Property__c.Days_On_Market__c (formula TODAY() - Date_Listed__c, blanks as zero) is not immutable, so it cannot be a generated column: it is a view column (and PropertyDto.daysOnMarket in the API).

```sql
SELECT p.*, CASE WHEN p."date_listed" IS NULL THEN 0 ELSE (CURRENT_DATE - p."date_listed") END AS "days_on_market" FROM "properties" p
```
